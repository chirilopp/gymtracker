# GymTracker для iPhone (SwiftUI, iOS 17+)

Подходит для iPhone 11 и iPhone 15 (и всех, где установлена iOS 17 или новее). Работает офлайн, без регистрации.
Это порт Android-версии: календарь тренировок, шаблоны, экран упражнения со свайпом, свой отдых для каждого
упражнения, история, графики (Swift Charts), резервная копия JSON и экспорт CSV.

## ВАЖНО: статус проверки
Проект написан без Xcode и без Mac: **он не компилировался и не запускался**. При первой сборке возможны ошибки
компиляции — пришлите текст ошибки, я исправлю. Работа таймера в фоне, звука и вибрации на устройстве не проверялась.


## Версия 1.2 — расписание тренировок
- В шаблоне (Ещё → Шаблоны → шаблон) выберите **«Дни тренировок»**: Пн–Вс. Например, «Грудь/бицепс» — вторник и четверг.
- Блок **«Следующие тренировки»** на главном экране показывает тренировки текущей недели с кольцом выполнения; точка отмечает сегодняшний день. Нажатие открывает выполненную тренировку или запускает шаблон.
- В календаре будущие запланированные дни помечены «план» и названием шаблона; в выбранном дне показаны запланированные шаблоны.
- Сопоставление «план ↔ выполнено» идёт по названию шаблона и дате.

## Как получить приложение на iPhone

### Вариант A — есть Mac с Xcode 15+
1. `brew install xcodegen`, затем в папке проекта: `xcodegen generate` → откроется `GymTracker.xcodeproj`.
2. В Xcode: Signing & Capabilities → Team = ваш Apple ID (бесплатного достаточно), при необходимости поменяйте Bundle Identifier.
3. Подключите iPhone, выберите его как устройство, нажмите Run. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика (включить) и доверять профилю разработчика.

### Вариант B — только Windows (через GitHub)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий; загрузите в него все файлы этой папки (включая скрытую папку `.github`).
2. Вкладка **Actions** → «Build iOS IPA» → **Run workflow**. Через несколько минут скачайте артефакт `GymTracker-ipa` (внутри `GymTracker.ipa`).
3. Установите на Windows **Sideloadly** (sideloadly.io; для работы нужны iTunes и iCloud с сайта Apple) или **AltStore**.
4. Подключите iPhone кабелем, в Sideloadly выберите `GymTracker.ipa`, введите свой Apple ID, нажмите Start (программа подпишет приложение вашим Apple ID).
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверять вашему Apple ID; включите Режим разработчика (Настройки → Конфиденциальность и безопасность) и перезагрузите телефон.
6. Приложение, подписанное бесплатным Apple ID, работает **7 дней**; потом переподпишите тем же способом — данные сохранятся (не удаляйте приложение). Аккаунт Apple Developer (99 $/год) даёт подпись на год и TestFlight.

Первый запуск: разрешите уведомления — на них держится сигнал таймера при выключенном экране.

## Что отличается от Android-версии
- **Таймер отдыха в фоне:** на iOS нет фоновых служб. Конец отдыха фиксируется запланированным локальным уведомлением (сработает при выключенном экране и закрытом приложении). Внутри открытого приложения звук и вибрацию подаёт само приложение. Время хранится как момент окончания, поэтому отсчёт не «уплывает».
- **Звук:** обычный звук уведомления iOS (отдельные звуки выбрать нельзя). Боковой переключатель «Беззвучно» и режимы «Фокусирование» отключают звук/уведомление — на вибрацию это влияет по правилам iOS.
- Нет Live Activity / Dynamic Island (потребуется отдельное расширение приложения и платный аккаунт).
- Данные хранятся в одном JSON-файле в папке приложения (атомарная запись); есть номер версии формата. Резервная копия — тот же формат; импорт заменяет данные после подтверждения.
- Экспорт/импорт через системное окно «Файлы» (iCloud Drive или «На iPhone»).

## Реализовано
Календарь по дням с процентом и названием; выбор шаблона; обзор тренировки; экран упражнения (кольца: повторы, отдых, подходы; поля «кг/повторы» и «+»); отдых для каждого упражнения (одно касание — старт/сброс); секундомер тренировки на метках времени (пауза, восстановление после перезапуска); библиотека упражнений (поиск, группы, свои, переименование, мягкое удаление); шаблоны (подходы × повторы, порядок); история (просмотр, правка, копирование, удаление); прогресс (графики веса/повторений/объёма, рекорды, оценка 1ПМ подписана как расчётная); JSON-копия, CSV.

## Известные ограничения
- Не собиралось и не тестировалось (см. выше).
- Секундомер основан на системных часах: ручной перевод времени повлияет на отсчёт.
- Тёмная тема принудительная; язык интерфейса — только русский.
